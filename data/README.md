# Data

This directory will contain the record-level metadata/labels and pointers to the waveform data used in the study.

## Planned contents

- `record_labeling.csv` — final record labels, train/test assignment, and inclusion/exclusion information.
- `selected_records_training/` — selected training waveforms (to be added or linked after data archival).
- `selected_records_testing/` — selected testing waveforms (to be added or linked after data archival).

The large waveform collection is intentionally omitted from the initial repository. Do not commit the full waveform collection to ordinary Git history.
